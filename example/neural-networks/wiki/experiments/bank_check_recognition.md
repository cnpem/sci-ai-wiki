# Bank-Check Recognition System

- Task: reading fields and characters on bank checks.
- Model components: CNN-based character recognition combined with document-processing modules and, in the broader system, Graph Transformer Network composition.
- Metrics: record-level recognition performance and production throughput are described historically; exact modern-style benchmark reporting is not available here.
- Interpretation: demonstrates system integration and deployment relevance, not a controlled architecture comparison with ResNet or Transformer models.
