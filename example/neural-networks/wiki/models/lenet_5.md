# LeNet-5

LeNet-5 is a convolutional neural network for handwritten-character recognition described in [[lecun_gradient_based_1998]]. It combines learned local filters, shared parameters, nonlinear processing, subsampling, and a trainable classifier. The architecture is an early example of jointly learning image features and the recognition objective.

Its importance for this wiki is foundational: LeNet-5 makes the CNN inductive bias explicit, while [[resnet]] later adds residual pathways to make much deeper convolutional stacks easier to optimize.
